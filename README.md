# ระบบจองคิวออนไลน์ (SmartQueue - Online Queue Booking System)

ระบบจองคิวออนไลน์ที่ได้รับการออกแบบตามหลัก **Modern Minimal** ในโทนสีฟ้า ขาว และน้ำเงิน รองรับการใช้งานเต็มรูปแบบบนทุกอุปกรณ์ (**Responsive Design**: โทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์) ช่วยให้ผู้รับบริการสามารถเลือกประเภทบริการ วันที่ และช่วงเวลา พร้อมรับบัตรคิวดิจิทัลได้ทันทีจากทุกที่ ลดความแออัดและลดเวลารอคอย ณ สถานบริการ

---

## 🌟 ฟังก์ชันการทำงานหลัก (Key Features)

### 1. การออกแบบสไตล์ Modern Minimal
- **โทนสีหลัก**: ฟ้าสดใส (`#2563eb`), น้ำเงินเข้มสุภาพ (`#0f172a`, `#1e293b`), และขาวสะอาดตา (`#ffffff`, `#f8fafc`)
- **การจัดวาง**: เรียบหรู สะอาดตา มีระยะห่างที่พอดี (Comfortable whitespace)
- **ไอคอนและปุ่มกด**: มีไอคอนประกอบทุกเมนูและปุ่มกดระบุสถานะชัดเจน
- **รองรับทุกขนาดหน้าจอ**: Responsive ตั้งแต่มือถือ (375px+), แท็บเล็ต (768px+) จนถึงหน้าจอคอมพิวเตอร์และจอทีวีความละเอียดสูง

### 2. หน้าหลัก (Home)
- แสดงชื่อระบบ **"ระบบจองคิวออนไลน์ (SmartQueue)"** พร้อมคำอธิบายระบบ
- ปุ่มกดด่วน **"จองคิวเลย"** และ **"ตรวจสอบสถานะคิว"**
- การแสดงผลตัวเลขสถิติแบบสด:
  - จำนวนคิวที่กำลังรอรับบริการ
  - จำนวนคิวที่กำลังให้บริการ ณ ช่องบริการ
  - จำนวนคิวที่ให้บริการเสร็จสิ้นแล้ววันนี้
  - เวลาการรอเฉลี่ยโดยประมาณ
- **มอนิเตอร์คิวปัจจุบัน (Live Counter Board)** แสดงช่องบริการ 1, 2, 3 พร้อมสถานะว่าง/ให้บริการ
- การ์ดประเภทบริการทั้งหมด พร้อมระยะเวลาโดยประมาณ
- แนะนำ **ขั้นตอนการจองคิว 4 ขั้นตอน** เข้าใจง่าย

### 3. ระบบสมาชิกและการเข้าสู่ระบบ (Authentication)
- **สมัครสมาชิก**: ชื่อ-นามสกุล, เบอร์โทรศัพท์, อีเมล, รหัสผ่าน (พร้อมตรวจสอบความถูกต้องของข้อมูล)
- **เข้าสู่ระบบ**: ใช้อีเมลหรือเบอร์โทรศัพท์ พร้อมรหัสผ่าน
- **ระบบสิทธิ์ (Roles)**: สมาชิกทั่วไป (`user`) และผู้ดูแลระบบ (`admin`)
- **ปุ่มทดสอบด่วน (1-Click Demo Login)**: คลิกปุ่มเดียวสามารถสลับเป็นผู้ใช้ทั่วไปหรือ Admin เพื่อความสะดวกรวดเร็วในการทดสอบ

### 4. ระบบการจองคิว (Booking Wizard)
- **ขั้นตอนที่ 1 - เลือกบริการ**: แสดงการ์ดบริการ รหัสหมวดหมู่นำหน้า (เช่น A, B, C, D) และระยะเวลาให้บริการ
- **ขั้นตอนที่ 2 - เลือกวันและเวลา**:
  - เลือกวันที่ต้องการ (ตั้งแต่วันนี้ถึงล่วงหน้า 14 วันทำการ)
  - เลือกรอบเวลา (เช่น 09:00 - 09:30, 09:30 - 10:00, 10:00 - 10:30, ...)
  - **ระบบป้องกันการจองซ้ำ**: ตรวจสอบความจุต่อช่วงเวลา (Slot Capacity) หากเต็มจะขึ้นว่า "เต็มแล้ว" และป้องกันไม่ให้ผู้ใช้คนเดิมจองเวลาเดิมซ้ำ
- **ขั้นตอนที่ 3 - กรอกข้อมูลผู้จอง**:
  - ดึงข้อมูลสมาชิกมาแสดงให้อัตโนมัติ (แก้ไขได้)
  - กล่องสรุปรายละเอียดการจองก่อนกดยืนยัน
- **การสร้างหมายเลขคิวอัตโนมัติ**:
  - รันนิ่งหมายเลขอัตโนมัติตามหมวดและลำดับประจำวัน เช่น `A001`, `A002`, `B001`
- **บัตรคิวดิจิทัล (Digital Queue Ticket)**:
  - ดีไซน์บัตรคิวสวยงาม มีรอยปรุ บาร์โค้ดจำลอง และรายละเอียดครบถ้วน
  - รองรับการสั่งพิมพ์บัตรคิว (**Print Slip**) และเปิดไปหน้าติดตามคิวได้ทันที

### 5. หน้าตรวจสอบสถานะคิว (Live Queue Tracking)
- ค้นหาได้ด้วย **หมายเลขคิว** (เช่น A002) หรือ **เบอร์โทรศัพท์**
- แสดงข้อมูลละเอียด:
  - หมายเลขคิวของผู้ใช้
  - หมายเลขคิวที่กำลังให้บริการ ณ ช่องบริการ
  - จำนวนคิวที่อยู่ข้างหน้า (Queues Ahead)
  - เวลารอโดยประมาณ (คำนวณจากจำนวนคิวข้างหน้า × ระยะเวลาบริการ)
- **แถบความคืบหน้า 4 ขั้นตอน (Journey Progress Bar)**:
  1. จองสำเร็จ &rarr; 2. รอเรียกคิว &rarr; 3. เข้ารับบริการ &rarr; 4. เสร็จสิ้น
- **ระบบเสียงแจ้งเตือนอัจฉริยะ (Audio Callout Engine)**:
  - กริ่งคอร์ดดิงดอง (**Chime**) สร้างด้วย Web Audio API คุณภาพสูง
  - เสียงพูดประกาศภาษาไทย (**Thai Speech Synthesis**): *"ขอเชิญหมายเลขคิว [A002] ที่ช่องบริการ [1] ค่ะ"*
- อัปเดตข้อมูลอัตโนมัติแบบเรียลไทม์

### 6. หน้าประวัติการจอง (Booking History)
- แสดงประวัติการจองคิวทั้งหมดของผู้ใช้
- แท็บแยกสถานะ: **ทั้งหมด**, **รอรับบริการ**, **กำลังให้บริการ**, **ให้บริการแล้ว**, **ยกเลิกแล้ว**
- การดำเนินการ:
  - **ดูบัตรคิว** เพื่อเปิดดูบัตรคิวย้อนหลังหรือสั่งพิมพ์
  - **ยกเลิกคิว** ได้ตามเงื่อนไข (ยกเลิกได้เฉพาะคิวที่อยู่ในสถานะ "รอรับบริการ")
  - **ติดตามสถานะสด** ลิงก์ตรงเข้าสู่หน้า Live Tracker

### 7. แผงควบคุมผู้ดูแลระบบ (Admin Dashboard)
- มีระบบตรวจสอบสิทธิ์เฉพาะผู้ดูแลระบบ (`admin`)
- การ์ดสรุปตัวเลขสถิติ (KPIs) ประจำวัน
- **สถานีเรียกคิวหน้าเคาน์เตอร์ (Queue Calling Console)**:
  - เลือกช่องบริการ (ช่อง 1, ช่อง 2, ช่อง 3)
  - แสดงหมายเลขคิวปัจจุบันประจำช่องบริการนั้น
  - ปุ่ม **"เรียกคิวถัดไป (Call Next)"**: ดึงคิวถัดไปตามลำดับก่อน-หลัง (FIFO) อัปเดตสถานะเป็นกำลังให้บริการ พร้อมเล่นเสียงกริ่งและประกาศภาษาไทย
  - ปุ่ม **"เรียกซ้ำ (Recall)"**: ประกาศเรียกคิวเดิมซ้ำ
  - ปุ่ม **"ให้บริการเสร็จสิ้น (Complete)"**: บันทึกเวลาให้บริการเสร็จสิ้น
  - ปุ่ม **"ข้าม / ไม่มา (Skip/No-show)"**: สำหรับกรณีผู้รับบริการไม่มาตามนัด
- **ตารางจัดการรายการจอง**:
  - ค้นหาด้วยรหัสคิว ชื่อ หรือเบอร์โทรศัพท์
  - กรองตามวันที่ ประเภทบริการ และสถานะ
  - สลับเปลี่ยนสถานะคิวได้โดยตรงจากตาราง
- **ระบบจัดการประเภทบริการ (Services CRUD)**:
  - เพิ่มประเภทบริการใหม่ (ชื่อ, รหัสตัวอักษรย่อ Prefix เช่น E, ระยะเวลา, ความจุต่อรอบ)
  - แก้ไขข้อมูลบริการเดิม
  - ลบประเภทบริการ (พร้อมระบบตรวจสอบความปลอดภัย ป้องกันการลบบริการที่มีคิวรออยู่)
- **ปุ่มรีเซ็ตข้อมูลระบบ**: รีเซ็ตฐานข้อมูลกลับสู่ชุดข้อมูลตัวอย่างเริ่มต้นเพื่อการทดสอบ

### 8. หน้าจอมอนิเตอร์แสดงผลรวม (TV Display Mode)
- หน้าจอสำหรับเปิดบนสมาร์ททีวีหรือมอนิเตอร์ประจำโถงพักคอย
- พื้นหลัง Dark Theme ระดับพรีเมียม สบายตา มองเห็นได้ชัดเจนจากระยะไกล
- แสดงนาฬิกาดิจิทัลเรียลไทม์
- แสดงช่องบริการ 1, 2, 3 พร้อมหมายเลขคิวดิจิทัลขนาดใหญ่
- แสดงรายการลำดับคิวรอรับบริการถัดไป
- มีแถบประกาศตัววิ่งด้านล่าง

## 🏗️ โครงสร้างฐานข้อมูล (Database Schema)

ระบบรองรับทั้ง **Node.js REST API Server** (บันทึกไฟล์ JSON ถาวร) และ **LocalStorage Fallback** โดยมีโครงสร้างข้อมูลดังนี้:

| ตาราง / โมเดล | ฟิลด์ข้อมูลหลัก |
|---|---|
| **Users** | `id`, `name`, `phone`, `email`, `password`, `role` (`user` \| `admin`), `createdAt` |
| **Services** | `id`, `name`, `codePrefix`, `durationMinutes`, `maxPerSlot`, `description`, `icon`, `active` |
| **Bookings** | `id`, `queueNumber`, `userId`, `customerName`, `customerPhone`, `customerEmail`, `serviceId`, `date`, `timeSlot`, `note`, `status` (`waiting` \| `in_service` \| `completed` \| `cancelled` \| `no_show`), `counterNumber`, `calledAt`, `completedAt`, `createdAt` |

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

ระบบได้รับการพัฒนาแบบ **Zero-Dependency Native Stack** เพื่อให้สามารถเปิดใช้งานได้ทันทีบนทุกเครื่องโดยไม่มีปัญหาเรื่องการคอมไพล์ C++ หรือการดาวน์โหลดโมดูล:

### วิธีที่ 1: รันด้วย Node.js Server (แนะนำ)
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:

```bash
# รันเซิร์ฟเวอร์ Node.js (พอร์ตเริ่มต้น 3000)
node server.js
```
หรือหากมี npm:
```bash
npm start
```

จากนั้นเปิดเว็บเบราว์เซอร์ไปที่:
👉 **http://localhost:3000**

---

### วิธีที่ 2: เปิดใช้งานโดยตรงผ่านเบราว์เซอร์ (Standalone Mode)
หากไม่ได้ติดตั้ง Node.js หรือต้องการทดสอบหน้าเว็บทันที:
- ดับเบิลคลิกไฟล์ **`index.html`** เพื่อเปิดใน Google Chrome, Microsoft Edge, Safari หรือ Firefox
- ระบบจะเปิดใช้งาน **Client-side LocalStorage Engine** อัตโนมัติ ทุกฟังก์ชัน ปุ่มกด บันทึกข้อมูล บัตรคิว และเสียงประกาศจะทำงานได้อย่างสมบูรณ์ 100%

## 🛡️ มาตรฐานความปลอดภัยและการตรวจสอบข้อมูล (Validation)
1. **ตรวจสอบความถูกต้องก่อนบันทึก (Form Validation)**: ตรวจสอบเบอร์โทรศัพท์ รูปแบบอีเมล และความยาวของรหัสผ่าน
2. **การป้องกันการจองชนกัน (Concurrency Protection)**: ตรวจสอบจำนวนคิวในรอบเวลานั้นๆ ไม่ให้เกินโควต้าที่บริการกำหนด
3. **การรักษาความปลอดภัยของรหัสผ่าน**: ในการส่งข้อมูลผู้ใช้และจำแนกบทบาท จะมีการตัดฟิลด์รหัสผ่านออกก่อนส่งกลับ Client เสมอ
4. **ความสมบูรณ์ของคิว**: ป้องกันการยกเลิกคิวที่ให้บริการเสร็จสิ้นแล้ว และป้องกันการลบประเภทบริการที่มีคิวที่รอรับบริการอยู่
